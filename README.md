# Peluts · demostración de web

Demo de diseño web para **Peluts** (perruqueria canina i complements animals, Barcelona). No es la web oficial.

- Sitio estático: `index.html`, `peluqueria.html`, `tienda.html`, `tiendas.html`, `cita.html`.
- Estilos en `assets/css/site.css`, comportamiento en `assets/js/site.js`.
- Paleta y ornamento (loto, hojas, espirales) basados en el logotipo.
- Para añadir imágenes generadas, guardarlas como `assets/img/ia/<nombre>.webp` (se ocultan solas si no existen).
